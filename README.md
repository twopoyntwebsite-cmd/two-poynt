## 💎 Crystal Clear Glassmorphism Architecture

To achieve true **crystal clarity** rather than a cloudy or plastic appearance:
- **Specular Edge Highlighting:** Layered gradient borders (`border-top: 1px solid rgba(255, 255, 255, 0.45)`, `border-left: 1px solid rgba(255, 255, 255, 0.2)`) replicating physical refraction.
- **Backdrop Blur & Saturation:** `backdrop-filter: blur(24px) saturate(200%) contrast(110%)` allowing rich ambient background lights to refract cleanly.
- **Ambient Lighting Mesh:** Subtle gold (`#d4af37`), sapphire (`#14325a`), and amber orbs floating slowly in the background to provide deep optical depth.
- **Inner Specular Glows:** `box-shadow: inset 0 1.5px 1px 0 rgba(255, 255, 255, 0.35)` to simulate edge bevels on luxury glass.
